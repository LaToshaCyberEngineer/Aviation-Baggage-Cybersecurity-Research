## How to use these

1. Open the notebook and its matching README together. Follow the numbered notebook sections before studying the question bank.
2. Check the saved output tables and calculations in the current notebook before using exact percentages in a defense answer.
3. Explain the research result aloud without reading the code line by line; then answer the challenge questions.
4. Keep limitations clear. High model scores on synthetic patterns and modeled response benefits are not field measurements.

**Source version warning:** These guides were assembled from available previously supplied notebook snapshots. The most recent GitHub repository content could not be read directly in this session. Please reconcile any later code or output changes.

**Writing reviews:** Each file includes a transparent heuristic pattern review. These are not Turnitin results and cannot verify who wrote a passage.
